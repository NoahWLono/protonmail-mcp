# ChatGPT setup

This server is designed to stay on the same machine as Proton Mail Bridge. It binds only to
loopback and exposes a Streamable HTTP MCP endpoint at `http://127.0.0.1:8765/mcp` by default.

## 1. Run Proton Mail Bridge

Install Proton Mail Bridge, sign in, and open **Mailbox details**. Copy the IMAP username,
password, port, and security mode shown there. The IMAP password is generated by Bridge. It is
not your Proton Account password.

## 2. Configure protonmail-mcp

```bash
cp .env.example .env
chmod 600 .env
$EDITOR .env
```

Set the Bridge values exactly as shown in Mailbox details.

## 3. Install and verify

With `uv`:

```bash
uv sync --extra dev
uv run protonmail-mcp doctor
```

A healthy result reports `"ok": true` and a mailbox count. The doctor command does not read
message bodies.

## 4. Start the MCP server

```bash
uv run protonmail-mcp serve
```

The default endpoint is:

```text
http://127.0.0.1:8765/mcp
```

For local protocol testing, you can use MCP Inspector against that endpoint.

## 5. Connect ChatGPT

ChatGPT does not directly connect to localhost MCP endpoints. Use OpenAI Secure MCP Tunnel for
this local endpoint, then enable Developer Mode in ChatGPT and create a custom app using the
remote endpoint provided by the tunnel.

Current OpenAI help page:
https://help.openai.com/en/articles/12584461

The MCP itself does not implement user authentication because it never binds beyond loopback.
The secure tunnel is the boundary between ChatGPT and this local server.

## Security model

- IMAP target is loopback-only by default.
- MCP server is loopback-only, with no opt-out in this build.
- Mailboxes are selected with `readonly=True`.
- Message reads use `BODY.PEEK`, not `BODY[]`.
- No SMTP code exists.
- No IMAP STORE, COPY, MOVE, APPEND, EXPUNGE, or DELETE operation exists.
- Search results are capped.
- Full message fetches have a byte cap.
- Parsed email HTML is converted to inert text. Remote resources are never loaded.
- Attachments are reported as metadata only. Attachment bytes are not exposed as a tool.
- Every message response warns the model that email content is untrusted external data.

## Important platform limitation

At the time this project was generated, OpenAI documents custom MCP apps as a web feature, not a
mobile ChatGPT feature. Configure and use the app from ChatGPT on the web unless OpenAI expands
mobile support later.
